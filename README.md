# Legal Case Management

A web application for managing legal cases with role-based access for users and administrators.

## Tech Stack

- React
- TypeScript
- Vite
- Firebase Authentication
- Cloud Firestore
- React Router
- Material UI
- Firebase Storage

## Features

- User authentication and protected routes
- User dashboard
- Legal case creation and management
- Case search and categorization
- Admin dashboard
- Administrative case management
- User management and user search

## My Role

**Lead Developer**

Led the development of the application and contributed to its frontend implementation, Firebase integration, authentication flows, case-management functionality, and administrative interfaces.

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application requires a Firebase project configured for the repository's authentication and Firestore functionality. The original project configuration is retained in the repository for reference.
